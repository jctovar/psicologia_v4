📱 NAVEGACIÓN INTELIGENTE
-------------------------

El sistema navega automáticamente a la pantalla correcta según el tipo:

1️⃣  NAVEGAR A CALENDARIO
   ./send.sh \
     --title "Evento Próximo" \
     --body "Conferencia - 25 de Enero" \
     --data '{"type":"event"}'

2️⃣  NAVEGAR A HOME (NOTICIAS)
   ./send.sh \
     --title "Nueva Publicación" \
     --body "Artículo disponible" \
     --data '{"type":"post"}'

3️⃣  NAVEGAR A ÁREAS
   ./send.sh \
     --title "Nuevos Recursos" \
     --body "Materiales disponibles" \
     --data '{"type":"resource"}'

4️⃣  NAVEGAR A PROFESORES
   ./send.sh \
     --title "Actualización" \
     --body "Nuevos horarios" \
     --data '{"type":"teacher_update"}'
